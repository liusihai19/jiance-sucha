# 检测项目速查 · 标准版

建设工程质量检测九大专项速查页：**9 个专项 / 93 个检测项目 / 1005 条参数**，按「三源三档」组织。

- 版本：v3.2 · 2026-11-12（版式沿用原版紧凑卡片：参数 / 取样 / 依据；资质视角为头部小按钮，等级筛选在计数行）
- 形态：静态页，无构建依赖，可离线打开
- 在线：https://liusihai19.github.io/jiance-sucha/

## 三源三档

| 来源 | 作用 |
|---|---|
| 产品标准 | 给出参数全集（出厂检验、型式检验） |
| 验收规范 | 给出必检子集（进场复验、结构实体、竣工验收） |
| 资质标准 | 给出可选范围，仅用于「资质申请」视角 |

三档标注：

- **强制必检**：验收规范主控项目、结构实体检验、强制性条文、进场复验
- **条件必检**：满足触发条件时必须检（气候区、设计有要求、材料品种等）
- **可选**：规范未要求，按委托或资质需要

## 功能

- 双视角切换：工程验收 / 资质申请
- 筛选：专项、检测阶段、必检等级、只看未配置覆盖
- 检索：项目名、参数名、标准号、拼音与首字母
- 项目卡显示「强制 / 条件 / 可选」数量与产品标准覆盖率
- 参数行显示阶段、触发条件、依据条款、方法标准
- 页尾手机扫码

## 更新方法

1. 在本地维护目录修改 `corrections.json`（补参数、调等级、写触发条件）；
2. 在 Windows PowerShell 运行 `build.ps1` 重新生成 `data.js`；
3. 提交 `index.html` 与 `data.js`，GitHub Pages 约 1 分钟自动更新。

- 强制必检按现行验收规范判定，不采用资质标准的「必备参数」口径；资质口径单独保留在「资质申请」视角。
- 产品标准覆盖率已配置全部 93 个项目，项目卡显示「覆盖 X/X」；覆盖清单在 `coverage.json`，可继续细化。
