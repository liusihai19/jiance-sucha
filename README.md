# 检测项目速查 · 九大专项

建设工程质量检测（见证取样）速查页：按住建部 **9 个检测专项、93 个检测项目** 整理，逐项给出必备／可选检测参数、组批与取样量、检测参数与检验数量、依据标准（三分类）。

- 版本：v2.1 · 2026-11-12
- 形态：单文件静态页，无外部依赖，可离线打开
- 数据：9 专项 / 93 项目 / 215 本依据标准 / 32 条检测参数
- 检索：中文关键词、拼音、首字母、标准号（如 `水泥`、`shuini`、`sn`、`GB 50204`）

## 在线访问

启用 GitHub Pages 后访问：`https://<用户名>.github.io/<仓库名>/`

1. 修改 `index.html`（数据在 `<script>` 内的 `DATA` 数组中，`py` 字段为拼音索引）；
2. 同步修改页首 `v2.x · 日期` 与 `README` 中的版本号；
3. 提交推送，Pages 会自动重建（约 1 分钟）。

## 说明

- 检测项目与必备／可选参数取自建质规〔2023〕1号附件2《检测专项及检测能力表》。
- 取样组批、检验数量为现行标准常规值，实际以设计文件、经批准的检测方案及当地主管部门要求为准。
- 标准是否现行、替代关系及强制性条文，引用前请再核国家标准信息公共服务平台及住建部、交通运输部公告。
