# 检测项目速查 · 标准版

建设工程质量检测九大专项速查页：**9 个专项 / 93 个检测项目 / 988 条参数**，按「三源三档」组织。

- 版本：v3.0 · 2026-11-12
- 形态：静态页，无构建依赖，可离线打开
- 在线：https://liusihai19.github.io/jiance-sucha/

## 三源三档

| 来源 | 作用 |
|---|---|
| 产品标准 | 给出参数全集（出厂检验、型式检验） |
| 验收规范 | 给出必检子集（进场复验、结构实体、竣工验收） |
| 资质标准 | 给出可选范围，仅用于「资质申请」视角 |

三档标注：

- **强制必检**：验收规范主控项目、结构实体检验、强制性条文、进场复验
- **条件必检**：满足触发条件时必须检（气候区、设计有要求、材料品种等）
- **可选**：规范未要求，按委托或资质需要

## 功能

- 双视角切换：工程验收 / 资质申请
- 筛选：专项、检测阶段、必检等级、只看未配置覆盖
- 检索：项目名、参数名、标准号、拼音与首字母
- 项目卡显示「强制 / 条件 / 可选」数量与产品标准覆盖率
- 参数行显示阶段、触发条件、依据条款、方法标准
- 页尾手机扫码

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 页面 |
| `data.js` | 结构化参数数据（构建产物） |
| `qrcodegen.js` | 本地二维码库 |
| `corrections.json` | 人工修正表：补漏项、调等级、加触发条件 |
| `build.ps1` | 由旧版 DATA + corrections.json 生成 data.js |
| `参数矩阵模板.csv` | 后续维护用的参数矩阵模板 |

## 更新方法

1. 修改 `corrections.json`（补参数、调等级、写触发条件）；
2. 在 Windows PowerShell 运行 `build.ps1` 重新生成 `data.js`；
3. 提交 `index.html` 与 `data.js`，GitHub Pages 约 1 分钟自动更新。

## 说明

- 强制必检按现行验收规范判定，不采用资质标准的「必备参数」口径；资质口径单独保留在「资质申请」视角。
- 产品标准覆盖率目前配置了 13 个项目（水泥、钢筋、骨料、混凝土、防水卷材、保温材料、建筑外窗、沥青混合料等），其余项目显示「覆盖未配置」，可继续补充。
- 取样组批、检验数量为常规值，实际以设计文件、经批准的检测方案及当地主管部门要求为准。
- 标准是否现行、替代关系及强制性条文，引用前请再核国家标准信息公共服务平台及住建部、交通运输部公告。
